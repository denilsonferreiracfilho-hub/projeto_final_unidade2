O projeto

O PlanoUni é um projeto acadêmico da disciplina de Desenvolvimento Front-End para Web. Seu objetivo é ajudar universitários a organizar a rotina de estudos entre matérias, provas e trabalhos.

Como surgiu

O projeto surgiu da necessidade de organizar o tempo de estudo entre várias disciplinas, provas e trabalhos na universidade. A ideia é criar uma plataforma que ajude os estudantes a planejar seus estudos de forma eficiente.

Autor

Desenvolvido por Denilson Ferreira de Carvalho Filho, um universitário que está cursando o segundo período de Ciência da Computação.

Para quem é

Para estudantes universitários que precisam dividir o tempo entre várias disciplinas.
